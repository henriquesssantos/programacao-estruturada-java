Programação Estruturada e POO em Java ☕
Repositório dedicado ao armazenamento de exercícios, trabalhos acadêmicos e estudos práticos desenvolvidos durante as disciplinas de Programação Estruturada e Programação Orientada a Objetos (POO) em Java.

📌 Sobre o Repositório
Este repositório reúne implementações práticas dos conceitos fundamentais de desenvolvimento de software em Java, evoluindo da lógica de programação estruturada até a modelagem de domínio com orientação a objetos.

🎯 Conteúdos e Conceitos Aplicados
Entrada e Saída de Dados: Manipulação do buffer do teclado com a classe Scanner, formatação de saídas e tratamento de conversões numéricas (Integer.parseInt, Double.parseDouble).

Abstração e Encapsulamento: Criação de classes, atributos privados e métodos públicos de exibição e controle.

Construtores e Instanciação: Uso correto da palavra-chave this para atribuição de parâmetros aos atributos de objetos na memória.

Associação entre Objetos: Modelagem de relacionamentos entre entidades (ex: a classe Aluguel agregando instâncias de Cliente e Imovel).
